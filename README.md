# Venture — Analogue Pocket openFPGA

Release candidate: v1.0.0

## Features

Hardware-tested dual-mono audio

## Installation

Copy the `Cores` and `Platforms` directories onto
the corresponding directories of the Analogue Pocket SD card.

Game ROMs are not included.

Users must supply legally obtained compatible ROM data.

## Attribution
